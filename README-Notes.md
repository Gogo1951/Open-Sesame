# Open Sesame // Notes

> The maintainer's settled rulings for Open Sesame, kept so no review raises them again: exceptions to the Gogo1951 add-on Style Guide, and decisions it leaves open.

## Exceptions

None.

## Decisions

- Lockbox Tooltips on WoW Forever show the requirement without the player's rank, because Forever has no skill-line API.
- The Lockboxes scope row keeps the caption "Show for" with the values "For Rogues" / "For All Characters", by the maintainer's copy choice, not "Rogues Only / All Characters".
- The End of Support notice prints at every login, right after the welcome message, and has no toggle, so it shows even when the welcome message is off: every player should learn that Open Sesame now lives on inside GogoLoot.
- The mini-map tooltip opens with a Locked Items list, above the feature blocks and shown only while locked boxes wait in the bags, because that is what the player hovers the button to check.
- Loot Toasts was removed in the final release rather than fixed: it was buggy, and the fix ships in GogoLoot. Its saved settings are cleared from every profile at login.
